# İki gerçek ekran görüntüsü

Görüntüler henüz alınmadı; burada hazır/sahte ekran görüntüsü yoktur.

1. Windows'ta uygulamayı açın. İzinli bir yüz fotoğrafında algılama kutusunu gösterin. `Win+Shift+S` ile pencereyi yakalayıp `01-yuz-algilama.png` olarak bu klasöre kaydedin.
2. İki etikette örnek ekleyin, eğitin ve **eğitimde olmayan** bir görüntüde etiket + LBPH uzaklığını gösterin. İkinci yakalamayı `02-yerel-tanima.png` olarak kaydedin.
3. Public repo için yüzünü paylaşmak istemiyorsanız dosyayı yerelde bırakın; görünür yüz bölgesini paylaşım kopyasında bulanıklaştırıp kutu, etiket listesi, uygulama başlığı ve skorun görünür kaldığını kontrol edin. Gerçek çalışma kanıtı olarak düzenlendiğini belirtin. Gönüllülerin iznini alın.
4. PNG'ler eklendikten sonra ana README'ye aşağıdaki Markdown'ı ekleyin ve GitHub önizlemesini kontrol edin:

```markdown
![Yüz algılama](docs/screenshots/01-yuz-algilama.png)
![Yerel örneklerle tanıma](docs/screenshots/02-yerel-tanima.png)
```
