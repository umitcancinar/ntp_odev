# Gerçek ekran görüntülerini ekleme

Bu klasörde şu an gerçek PNG bulunmuyor. Windows'taki uygulama denemesinden sonra aşağıdaki iki resmi alın. Mockup, yapay görüntü veya başka uygulama ekranı kullanmayın.

1. **`01-metinden-sese.png`**: Formu açın, seçili sesin diline uygun kişisel veri içermeyen bir metin yazın. Ses/hız seçimini ve metni gösterin. Başlat ardından Duraklat seçeneğini kullanarak duraklatılmış gerçek durumu yakalayın. Windows Ekran Alıntısı Aracı (`Win+Shift+S`) ile formu çekip bu adla PNG kaydedin.
2. **`02-sesten-metne.png`**: Kurulu tanıyıcının dilini seçin; o dilde kişisel veri içermeyen bir cümle söyleyin. Gerçek metin, tanıyıcı dil kodu, son sonuç bilgisi ve “Mikrofon AÇIK” durumu görünürken formu çekin. Ardından Dinlemeyi durdur seçin. Türkçe tanıyıcı yoksa gerçekten desteklenen dil kullanın.
3. Görsellerin okunaklı olduğuna ve kişisel bilgi/başka pencereleri içermediğine bakın.
4. İki dosya gerçekten oluştuktan sonra README'nin ekran görüntüsü bölümündeki bekliyor bilgisini güncelleyin ve aşağıdaki Markdown'ı ekleyin:

```markdown
![Metinden sese: gerçek Windows uygulamasında okuma duraklatıldı](docs/screenshots/01-metinden-sese.png)
![Sesten metne: gerçek mikrofon diktesi sonucu ve seçili tanıyıcı](docs/screenshots/02-sesten-metne.png)
```

5. PNG ve güncel belgeleri gerçek bir commit ile kaydedin. Öğrenci adı/numarası ile Windows kontrol listesini de tamamlayın. GitHub'daki README üzerinde iki görselin açıldığını doğrulayın.

Mikrofon/tanıyıcı kullanılamıyorsa hata mesajının ayrı gerçek ekran görüntüsünü çekebilirsiniz; bu dosyayı başarılı dikte yapılmış gibi adlandırmayın veya teslim koşulu tamamlandı diye işaretlemeyin.
