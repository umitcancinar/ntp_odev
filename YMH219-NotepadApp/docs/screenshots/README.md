# Windows Ekran Görüntüsü Yönergesi

Föy gereğince README dosyasında en az 2 gerçek uygulama ekran görüntüsü bulunmalıdır. Windows ortamında uygulamayı çalıştırdıktan sonra aşağıdaki adımları uygulayınız:

1. **Birinci Ekran Görüntüsü (`01-not-listesi-ve-duzenleme.png`):**
   - Uygulamayı açın. Birkaç örnek not ekleyin (ör. Ders notu, Kişisel not).
   - Bir not seçili durumdayken, başlık, kategori ve içerik metni ekrandayken `Win + Shift + S` ile pencereyi yakalayın.
   - Bu klasöre `01-not-listesi-ve-duzenleme.png` adıyla kaydedin.

2. **İkinci Ekran Görüntüsü (`02-arama-ve-disa-aktarma.png`):**
   - Arama kutusuna bir kelime yazıp filtrelenmiş sonuçları gösterin veya "TXT Olarak Dışa Aktar" diyaloğu açıkken yakalayın.
   - Bu klasöre `02-arama-ve-disa-aktarma.png` adıyla kaydedin.

Ekran görüntüleri bu klasöre eklendikten sonra ana `README.md` dosyasındaki ilgili görsel bağlantıları otomatik olarak aktifleşecektir:
```markdown
![Not listesi ve düzenleme](docs/screenshots/01-not-listesi-ve-duzenleme.png)
![Arama ve TXT dışa aktarma](docs/screenshots/02-arama-ve-disa-aktarma.png)
```
